# Траблшутінг

**Плата не в мережі, AP AIRALERT-XXXX теж немає.** Серіал 115200: дивіться
[WIFI]-рядки. `forgetwifi` → підніметься AP з паролем у лозі.

**`DEVICE NOT READY: no API token`.** Токен не заданий: Web UI → API, або
серіал `settoken <...>`.

**API_AUTH_ERROR 401 у журналі.** Токен невалідний/відкликаний. Пристрій сам
після 15 поспіль 401 сповільнює запити до 1/5 хв. Новий ключ: api.ukrainealarm.com. **401 у ukrainealarm.com — це ще й
rate-limit**: приймається ~3 запити/хв на ключ, решта отримує порожній 401,
ідентичний відповіді на неправильний ключ. На темпі 20 с це ~1 з 3 опитувань,
прошивка просто опитує далі; «unauthorized»/API_401 — лише після 15 поспіль
(ключ справді невірний або використовується ще кимось паралельно — квота
спільна на ключ).

**`Дані застарілі` на дашборді.** API або інтернет недоступні. Останній
відомий стан тривоги утримується — це навмисно (Invariant 1). Дивіться
журнал: API_OFFLINE/API_429.

**Реле клацнуло при прошивці/буті.** Немає зовнішнього підтягування —
HARDWARE.md, розділ «Реле».

**RELAY_SAFETY_TRIP у журналі.** Патерн просив реле довше ліміту — guard
відрубав. Перевірте профілі сигналів: блоки «Гудить», що стоять підряд
(або на стику повторів), звучать як одне безперервне УВІМК — редактор у
Web UI підсвічує такі блоки помаранчевим.

**Пароль адміністратора забуто.** Серіал: `setpass <новий>`.

**Крашиться з Exception, серіал показує stack.** Декодування:
`python3 ~/.platformio/packages/framework-arduinoespressif8266/tools/…` або
addr2line по `.pio/build/nodemcuv2_dev/firmware.elf`. Якщо перед крашем
`heap=` < 15000 — шукайте витік (SPEC 128: heap-діагностика в /api/v1/system).

**Після невдалого OTA не бутиться.** Прошивка по кабелю:
`py -3 -m esptool --port COM3 write-flash 0x0 firmware.bin` (конфіг у
LittleFS вціліє — він поза sketch-областю).
